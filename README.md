# Cadete A · C.D. San Pedro

App de control de minutos jugados y multas del equipo.

## Cómo publicarla en GitHub Pages

1. Sube **todos** los archivos de esta carpeta (`index.html`, `manifest.json`, `icon-192.png`, `icon-512.png`, `.nojekyll`) a la raíz de tu repositorio, tal cual, sin renombrar nada.
   - Si ya tenías otro archivo `.html` en el repositorio de un intento anterior, bórralo antes para evitar confusiones.
2. En el repositorio: **Settings → Pages → Source: Deploy from a branch → Branch: main /(root) → Save**.
3. Espera 1-2 minutos y recarga la página de Settings → Pages: ahí aparece la URL pública (algo como `https://tu-usuario.github.io/tu-repositorio/`).
4. Abre esa URL en el navegador del móvil (Safari o Chrome) y usa "Añadir a pantalla de inicio".

Los datos (jugadores, partidos, multas) se guardan en el propio navegador del dispositivo donde se use.
